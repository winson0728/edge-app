# device-adapter（範本）

device-adapter-sdk 產出的設備接入範本（Connector → MQTT 標準 telemetry；可選 EdgeX Device Service 出口）

| 項目 | 內容 |
|---|---|
| Pack | IoT/OT |
| 層級 | Node、Gateway |
| 架構 | amd64, arm64 |
| 授權 | 自研（專有） |
| 來源 | **骨架 chart**（自研模組尚未有程式與映像；映像位置為必填參數） |

密碼與金鑰請先建立 Secret，再在表單填 Secret 名稱；進階參數用 **Edit YAML**。
