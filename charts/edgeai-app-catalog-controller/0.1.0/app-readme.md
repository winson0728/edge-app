# edge-app-catalog-controller

App Catalog（AppPack 目錄、preflight、授權 JWT 驗證、GitOps values commit；ZTP／OTA 子系統掛點）

| 項目 | 內容 |
|---|---|
| Pack | Platform |
| 層級 | Hub |
| 架構 | amd64, arm64 |
| 授權 | 自研（專有） |
| 來源 | **骨架 chart**（自研模組尚未有程式與映像；映像位置為必填參數） |

密碼與金鑰請先建立 Secret，再在表單填 Secret 名稱；進階參數用 **Edit YAML**。
